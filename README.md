## What is in this repo

A repo (short for repository) is the folder for your project that lives on GitHub.

| File or folder | What it is for |
| --- | --- |
| `index.html` and `styles.css` | Your venture website: the page people see first. |
| `prototype/` | Your working prototype. Start in `prototype/app.js`. |
| `docs/money-model.md` | Your money model: price, costs and break-even. |
| `docs/marketing-plan.md` | Your marketing plan: who, what message, where. |
| `docs/pitch.md` | Notes for your Demo Day pitch. |
| `.github/copilot-instructions.md` | Tells GitHub Copilot and your local AI how to help you. |
| `vercel.json` and `.nojekyll` | Settings for Vercel and GitHub Pages. You can leave them alone. |

## How to run it on your computer

1. Open this folder in VS Code.
2. Install the "Live Preview" extension by Microsoft, if you have not already.
3. Open `index.html` (or `prototype/index.html`).
4. Click the preview icon at the top right, or right-click the file and pick "Show Preview".
5. Change something and save. The preview updates on its own.

## How to save your work

A commit is a saved snapshot of your changes with a short message. A push sends your commits up to GitHub.

1. Open the Source Control view in VS Code.
2. Click "+" next to the files you changed.
3. Type a short message, like "Add sign-up button".
4. Click "Commit" (the button with a tick), then "Sync Changes".

## How to put it online

To deploy means to put your site on the internet so anyone with the link can open it.

- Aged 16 or over: you can use **Vercel**. Import this repo at vercel.com and click "Deploy".
- Aged 13 to 15: use **GitHub Pages**. In this repo open "Settings", then "Pages", pick "Deploy from a branch", branch "main", folder "/ (root)", and click "Save".

Your playbook in VentureOS walks you through each click.
