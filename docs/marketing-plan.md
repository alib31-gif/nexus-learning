# Marketing plan

This file is a placeholder. In week 8, open the Marketing Plan in VentureOS, fill it in, then copy the file it makes and paste it over this one.

A marketing plan answers:

- **Who** exactly are you trying to reach?
- **What** one message will make them care?
- **Where** will they see it? Pick 3 places and say why.
- **First 10:** the names of the first 10 people you will reach.
