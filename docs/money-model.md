# Money model

This file is a placeholder. In week 7, open the Money Model in VentureOS, fill it in, then copy the file it makes and paste it over this one.

A money model answers three questions:

- **Price:** what will you charge?
- **Costs:** what does it cost you to run?
- **Break-even:** how many customers do you need so the money coming in covers your costs? That number is your break-even point.
